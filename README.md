# Sala de Espera

Sudoku e Minas numa app web instalável (PWA), feita para jogar nos intervalos.

## Jogos
- **Sudoku** com três dificuldades, sempre com solução única. Inclui notas a lápis, desfazer e pistas (+30 s de penalização).
- **Minas** com tabuleiros de 9×9, 16×16 e 30×16. O primeiro clique nunca rebenta e há recorde por dificuldade.

## Instalar no iPhone
1. Abrir o endereço do GitHub Pages no Safari.
2. Tocar em Partilhar → Adicionar ao ecrã principal.
3. Abrir pelo ícone: a app corre em ecrã inteiro e funciona offline.

No Android, ou no Chrome e no Edge do computador, a opção chama-se "Instalar app".

## Atualizar
Depois de alterar ficheiros, subir a versão em `sw.js` (`sala-v1` → `sala-v2`) para os aparelhos já instalados receberem a cópia nova.

## Privacidade
A app não tem contas, publicidade nem estatísticas, e não envia dados para lado nenhum. Os jogos a meio e os recordes ficam guardados apenas no armazenamento local do teu browser. As fontes são carregadas do Google Fonts na primeira utilização.
